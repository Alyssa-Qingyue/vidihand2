# ViDiHand V2 project page

Static project page: https://alyssa-qingyue.github.io/vidihand2/

## Preview

Run `python -m http.server 8080` in this directory and open http://localhost:8080.

## Files

- `index.html`: page content and asset references.
- `v2/style.css` and `v2/app.js`: responsive layout, synchronized comparisons and sortable metrics.
- `v2/demo-v46.mp4`, `v2/demo-title-v40.jpg` and `v2/demo.vtt`: current narrated demo, poster and captions.
- `v2/qualitative/scenes-v47.json`: six cases from Figures 5 and 6, their provenance and playback configuration. Each case has one synchronized video atlas and a poster per method. Method panels show 2D reconstruction above 3D hands and wrist trajectories.
- `v2/results.json`: 18 baselines and ViDiHand V2, with in-domain and in-the-wild evaluation values.
- `v2/method.png` and `v2/teaser.png`: architecture figure and social preview image.
- `.github/workflows/`: GitHub Pages deployment on pushes to `main`.

Music in the narrated demo: [Horizons — Scott Buckley](https://www.scottbuckley.com.au/library/horizons/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
